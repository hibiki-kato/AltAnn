# Original UniAnn fixtures

`uniann-fixture.gff3` and `uniann-fixture.trace` were generated by Aleksey
Zimin's seven-state UniAnn executable, built from upstream commit
`91477a69e1a949fed082c4662b348d9a7a91ca2b`. They are independent of AltAnn's
decoder. The synthetic sequence and scores come from the unmodified default
`write_fixture` function in `tests/fixtures.py`.

To regenerate, call `write_fixture` in a temporary directory, then run the
upstream binary with these positional arguments:

```text
uniann fixture.fa emissions.txt gt.txt ag.txt atg.txt stop.txt
```

Save stdout as `uniann-fixture.gff3`. Retain the `dp` and `bt` rows from stderr
as `uniann-fixture.trace`, preserving row order and the final newline. There
are 1,200 positions and 2,400 trace rows. These logs retain UniAnn's original
integer serialization; AltAnn must reconstruct exact scores from the inputs.

The reverse-mode checks use the same oriented synthetic input and trace,
then verify output reflection independently. The real S. pombe validation
uses separately scored forward and reverse-complemented sequences; see
[validation](../../docs/validation.md).
